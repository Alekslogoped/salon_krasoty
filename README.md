# Салон маникюра

Свободная творческая игра для ребёнка: две SVG-кисти, десять независимых ноготков и уютный стол. Без заданий, таймера, оценок, регистрации, сервера и внешних сервисов. Весь интерфейс на русском.

## Возможности

- 14 цветов лака; индивидуальная покраска и «Покрасить все».
- Френч, горошек, полоски, сердечко, цветочек и звёздочки; рисунок можно снять отдельно.
- Четыре вида страз с размещением в точке нажатия, максимум 15 на ноготке.
- Золотые, серебряные и разноцветные блёстки; индивидуальное и массовое нанесение на окрашенные ногти, удаление слоя.
- Четыре кольца и четыре браслета. Руку для каждого украшения можно выбирать независимо.
- История до 80 действий; массовые действия отменяются целиком. Ластик очищает только выбранный ноготь. Сброс требует подтверждения и тоже отменяется.
- «Готово» доступно после покраски всех ногтей и выбора кольца и браслета. Финальный просмотр сохраняет возможность продолжить украшать.
- PNG 1800 × 1260 с руками, столом и всеми украшениями, без панели инструментов.
- Автоматическое сохранение маникюра в localStorage, если браузер разрешает. При недоступном хранилище игра работает в памяти.
- Мышь, касания, клавиатура (Tab, Enter или пробел на ноготке), адаптация размеров и уменьшение анимации по настройке системы.

Декор обрезается по контуру ногтя. Координаты страз вычисляются через обратную матрицу преобразования SVG, включая отражение правой руки. Расположение блёсток сохраняется в состоянии и не меняется при перерисовке.

## Файлы

| Файл         | Назначение                                                       |
| ------------ | ---------------------------------------------------------------- |
| `index.html` | Интерфейс, игровые панели и диалоги                              |
| `style.css`  | Оформление, адаптация, анимации                                  |
| `script.js`  | Интерактивная графика, состояние, инструменты, история и экспорт |
| `README.md`  | Запуск, публикация и встраивание                                 |

**Иллюстрации:** `assets/salon-table.png` — стол и подложка; `assets/client-hands.png` — две изящные руки с округлыми, немного отросшими натуральными ноготками; `assets/jewelry-sheet.png` — восемь нарисованных колец и браслетов с прозрачным фоном. Публикуйте папку `assets` целиком.

Все ресурсы локальные, пути относительные. Стол, руки, кольца и браслеты — созданные для игры PNG-иллюстрации; флакончики, иконки и декор ногтей — чёткие SVG-рисунки. Каждое украшение отображается через отдельное окно общей иллюстрации, без сторонних ресурсов. Контуры всех десяти ногтей подогнаны к иллюстрации и масштабируются вместе с ней. При экспорте локальные PNG встраиваются в SVG как данные: итоговая картинка содержит фон и руки без обращения к внешним сервисам. Устанавливать npm-пакеты для игры не требуется.

## Локальный запуск

Из каталога репозитория:

```sh
python3 -m http.server 8000
```

Откройте `http://localhost:8000` в своём браузере. Для остановки — Ctrl+C. В облачной среде проверка выполняется внутренними HTTP-запросами и браузерным тестированием; адрес localhost не является публичной ссылкой.

Для всех возможностей, включая экспорт PNG, запускайте игру по HTTP/HTTPS: через локальный сервер выше или GitHub Pages. При открытии `index.html` как локального файла браузер может запрещать загрузку иллюстраций для экспорта.

## Публикация на GitHub Pages

Публикация GitHub Pages настраивается отдельно от загрузки файлов в репозиторий. Адрес сайта считается опубликованным только после успешного развёртывания.

1. Сохраните файлы игры **вместе с папкой `assets`** в корне репозитория `Alekslogoped/salon_krasoty`, сделайте commit и отправьте его в ветку `main`.
2. На GitHub откройте **Settings → Pages**.
3. В **Build and deployment** выберите **Deploy from a branch**.
4. Выберите ветку **main** и папку **/ (root)**, нажмите **Save**.
5. Дождитесь завершения развёртывания. Фактический адрес возьмите со страницы **Settings → Pages**; сначала откройте его и проверьте игру.

Если файлы размещены в папке `docs`, выберите **/docs** вместо корня. Игра поддерживает размещение в подпапке без изменения путей. Jekyll, сборщик и платные API не нужны.

## Genially

После публикации замените `GAME_URL` фактическим HTTPS-адресом игры. Ниже **шаблон**, а не готовая опубликованная ссылка:

```html
<iframe
  src="GAME_URL"
  title="Салон маникюра"
  width="960"
  height="540"
  style="width:100%; aspect-ratio:16/9; border:0;"
  allow="fullscreen"
></iframe>
```

Вставьте код в компонент внешнего содержимого/встраивания Genially. Рекомендуемый размер контейнера — от 800 × 450 в горизонтальной ориентации. Полноэкранный режим необязателен.

Если платформа добавляет `sandbox`, для игры нужны `allow-scripts`, для скачивания — `allow-downloads`, для открытия отдельно — `allow-popups`. `allow-same-origin` позволяет пользоваться сохранением состояния, когда это также разрешено политикой браузера. Без доступа к хранилищу игра работает, но маникюр не сохраняется после перезагрузки.

Кнопка сохранения сначала создаёт PNG, затем инициирует скачивание и показывает изображение с повторной ссылкой. Если браузер блокирует скачивание внутри встраивания, используйте «Открыть игру отдельно». Интерфейс не утверждает, что файл сохранён на устройство: проверить скачивание нужно в самом браузере.

## Выполненные проверки

Реальные пользовательские действия автоматизированы Playwright в установленном Chromium:

- Все десять ногтей окрашены по отдельности; соседние ногти не изменяются.
- Перекраска сохраняет рисунок, стразы и расположение блёсток; новый рисунок заменяет старый.
- Проверены шесть дизайнов и удаление рисунка.
- Несколько страз размещаются в локальных координатах; лимит 15 и запрет нанесения на кожу работают.
- Блёстки наносятся индивидуально и массово; массовая покраска и блёстки отменяются одним действием.
- Ластик очищает только выбранный ноготь. Украшения размещаются на разных руках независимо.
- Проверены условия финала, продолжение игры, подтверждение сброса, восстановление состояния после перезагрузки и PNG со всеми слоями.
- Размеры 1920 × 1080, 1366 × 768, 1024 × 768, 960 × 540, 800 × 450 и 390 × 844: нет горизонтальной прокрутки, ногти видны, масштабированные координаты совпадают. На узком телефоне инструменты располагаются снизу; допускается вертикальная прокрутка.
- Проверены сенсорное нажатие, управление ногтем с клавиатуры, 35 последовательных отмен, работа при запрещённом localStorage, iframe с другим origin и изменение размера его контейнера.
- PNG из обычной страницы и iframe действительно создан и получен браузером; размер 1800 × 1260. Результат осмотрен визуально.
- Иллюстрации и PNG-экспорт проверены также при размещении в подпапке репозитория.
- Нет ошибок JavaScript или внешних запросов за ассетами. HTTP-загрузка HTML/CSS/JS и проверка синтаксиса JavaScript прошли.

Ограничения проверки: реальный опубликованный GitHub Pages и интерфейс Genially пока не проверены; Safari/Firefox и физический планшет в этой среде не запускались. Браузер или платформа встраивания могут ограничивать хранилище и скачивания.
